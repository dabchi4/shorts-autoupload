# Автозаливка Shorts на YouTube и TikTok

Кладёшь ролик в папку — скрипт сам заливает его на YouTube-каналы и ставит в отложку TikTok:
название, описание, теги, плейлист, игра, обложка, «Похожее видео», «не для детей», расписание по слотам.

- **YouTube** — через YouTube Studio в браузере [ShardBrowser](https://github.com/ProxyShard/ShardBrowser)
  (Playwright/patchright по CDP). Без YouTube API, без аудита, несколько каналов и Google-аккаунтов.
- **TikTok** — через официального партнёра [Buffer](https://buffer.com) (API) + хостинг видео в Cloudflare R2.
  Есть и запасной способ через браузер.
- **Защита от дублей** — сверка папок с уже выложенным по названию и длительности + метки в папке ролика.

```
D:\Видео\Мой канал\
  2026-11-16 Как пройти игру за 5 минут\
    Как пройти игру за 5 минут.mp4
    info.txt          ← название, дата, описание… (всё необязательно)
    uploaded.txt      ← появится после заливки на YouTube
```

```bash
python run.py --profile Main --plan     # показать, что и когда уйдёт на YouTube
python run.py --profile Main            # залить
python run.py --profile Buffer          # поставить в отложку TikTok
python check.py --profile Main          # отчёт: что уже залито, что нет
```

**Полная инструкция по установке и настройке — [docs/GUIDE.md](docs/GUIDE.md).**

## Что умеет

| | YouTube | TikTok (Buffer) |
|---|---|---|
| Название, описание, теги | ✅ | ✅ подпись |
| Своя обложка | ✅ (канал с подтверждённым телефоном) | кадр из видео |
| Плейлист, игра, «не для детей», ИИ-контент | ✅ | ИИ-метка |
| «Похожее видео» Shorts | ✅ | — |
| Анкета «Требования рекламодателей» | ✅ «Ничего из указанного» по настройке | — |
| Отложенная публикация по слотам | ✅ | ✅ (до 10 дней вперёд) |
| Несколько каналов / аккаунтов | ✅ переключение каналов и Google-аккаунтов | ✅ |
| Пропуск уже выложенного | ✅ | ✅ |

Скорость: около 30 секунд на ролик на YouTube, 10 секунд на TikTok.

## Структура

```
run.py              заливка (YouTube / TikTok)
check.py            что уже залито: сверка папок с каналами, метки
tools/relink.py     массово заменить «Похожее видео» в недавних Shorts
tools/probe.py      проверить связку ShardBrowser → Studio
tools/exec.py       отладка: выполнить сниппет в открытом профиле
yz/                 модули: studio (YouTube), buffer (TikTok API), tiktok (TikTok браузер),
                    info (info.txt), match (поиск дублей), schedule (слоты), shard/browser
docs/GUIDE.md       установка и настройка
docs/research.md    разбор опенсорс-аналогов и селекторов Studio
examples/info.txt   пример info.txt со всеми полями
```

## Важно

Автоматизация YouTube Studio через браузер — серая зона правил YouTube. Проект рассчитан на заливку
**своих** роликов на **свои** каналы в человеческом темпе. Используйте на свой риск.
